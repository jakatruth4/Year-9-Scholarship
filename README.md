## How to Navigate This Repository

Each folder at the top of this repository contains a standalone project, challenge, or topic:

- **`/projects`** — Personal apps, scripts, and larger coding experiments.
- **`/challenges`** — Coding problems, algorithm practice, and competition prep.
- **`/exploration`** — Notes, tutorials, and small tests from learning new languages or tools.

*(Note: Every individual folder includes its own short `README.md` explaining what the program does, how to run it, and what I learned from building it.)*
