# LeetCode Challenges

Solutions to algorithmic problems from [LeetCode](https://leetcode.com/).

## Purpose

I use LeetCode for languages I am **more experienced in** (such as Python and C++). Working in familiar languages lets me concentrate on deeper computer science concepts—including data structures, algorithm design, edge-case handling, and Big-O time/space complexity.

## Structure & Running Code

- Files are grouped by algorithmic topic (e.g., `arrays-and-hashing/`, `graphs-and-trees/`, `dynamic-programming/`) and prefixed with the problem number for easy sorting.
- Each file includes a header comment noting the problem link, approach, and time/space complexity, along with a local runner/test block so it can be executed outside of LeetCode's web editor.
