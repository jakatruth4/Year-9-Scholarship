# Edabit Challenges

Solutions to coding prompts from [Edabit](https://edabit.com/).

## Purpose

I use Edabit specifically to practice languages I am **less experienced in** (such as Rust, C#, or TypeScript). Because the problems are concise and self-contained, they allow me to focus on learning clean syntax, language idioms, and built-in data types through repetition.

## Structure & Running Code

- Files are organized by topic (e.g., `arrays/`, `strings/`, `logic/`) and named after the problem.
- Each solution includes a brief header comment and sample inputs/test cases at the bottom so it can be compiled or run directly from the terminal.
