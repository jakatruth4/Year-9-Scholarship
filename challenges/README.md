# Coding Challenges

This directory contains solutions to coding problems I complete outside of regular classwork to sharpen my programming fluency and algorithmic thinking.

I split my practice across two platforms depending on my goal for a given language:

- **[Edabit](./edabit)** — Used for languages I am less experienced in. Short, focused prompts help me build muscle memory with syntax, standard libraries, and basic problem-solving patterns before tackling larger tasks.
- **[LeetCode](./leetcode)** — Used for languages I am more experienced in. Longer algorithmic problems let me focus on data structures, optimization, edge cases, and time/space complexity without getting slowed down by unfamiliar syntax.
